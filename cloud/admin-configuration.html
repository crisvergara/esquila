Configuración de galpones

Configura las estaciones, los colores, los códigos y las preguntas de cada servidor. El galpón guarda una copia y sigue contando sin internet.

Quitar colores o respuestas los oculta para nuevos conteos; los registros anteriores se conservan. Un animal en curso termina con la configuración con que se inició. Actualiza la aplicación del galpón antes de publicar preguntas nuevas.
